# HyperFrames Video Studio

AI-assisted vertical video studio for creating 9:16 social videos.

## Planned stack

- React web application
- HyperFrames workflow
- Remotion for video composition and MP4 rendering
- Taste Skill (design-taste-frontend)
- Impeccable design workflow
- Emil Kowalski skills for animation and interaction quality

## Core workflow

1. Create a vertical 9:16 project.
2. Add images/media.
3. Add text and captions.
4. Add audio.
5. Preview the composition.
6. Render/export MP4.
7. Keep the workflow simple enough to operate through ChatGPT and AI coding agents.

## Design direction

Clean, modern creator-studio UI with strong typography, useful motion, responsive controls, and a practical editing workflow.
